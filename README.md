# Data Governance for AI Safety: A PM’s Lifecycle Framework

### The Problem
AI Safety isn't just a modeling problem; it's a data quality problem. This project applies 5 years of **Data Solution Project Management** experience to create a rigorous, verifiable pipeline for Red-Teaming datasets. We move past "quantity" and focus on "provenance."

### Research Thesis
Drawing from **Gebru et al. (2021)**, this framework treats data as a governed product. It implements multi-stage SME (Subject Matter Expert) validation and Inter-Annotator Agreement (IAA) to eliminate "noisy labels" in safety evaluations.

### Key Deliverables
* **Annotation_Protocol.md**: The definitive 5-stage guide for labeling intent and ambiguity.
* **QA_Workflow.md**: The PM process for SME validation and error-correction loops.

### References
